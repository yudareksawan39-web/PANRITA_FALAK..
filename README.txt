PANRITA FALAK — PEMBARUAN VISUAL KONSEP

Isi paket:
- index.html
- style.css
- script.js
- config.js
- gambar sampul, logo, dan gerbang IAIN Parepare

Pembaruan:
1. Penyegaran visual seluruh antarmuka dengan palet biru malam, emas, dan mode terang yang lebih bersih.
2. Mode terang/gelap menerapkan warna pada kartu, formulir, tabel, navigasi, dan panel perhitungan.
3. Halaman Posisi Matahari memiliki visual langit fajar, siang, senja, dan malam yang berubah mengikuti perhitungan posisi Matahari.
4. Efek Matahari disembunyikan saat Matahari berada di bawah horizon.
5. Fitur inti lama dipertahankan dalam struktur proyek.

Menjalankan:
- Ekstrak seluruh isi ZIP ke satu folder.
- Buka folder di VS Code.
- Jalankan index.html melalui Live Server (disarankan), karena beberapa fitur seperti GPS, sensor, dan peta memerlukan lingkungan browser yang sesuai.

Catatan pengujian:
Pemeriksaan sintaks JavaScript dan struktur ZIP dilakukan. Belum dilakukan uji langsung pada seluruh browser/HP. Visual langit adalah simulasi ilustratif berbasis posisi Matahari; bukan observasi cuaca atau foto langit live. Hasil astronomi perlu dibandingkan dengan ephemeris tepercaya untuk validasi presisi sebelum dipakai sebagai acuan observasi resmi.
