PANRITA FALAK — MODUL TEODOLIT FALAK

Fitur lama dipertahankan; modul Teodolit Falak ditambahkan:
- Kamera dan pembacaan sensor orientasi (perkiraan)
- Koordinat GPS, akurasi lokasi, dan azimut kiblat
- Materi penggunaan teodolit berdasarkan materi rujukan
- Perbandingan azimut aplikasi dengan teodolit fisik

Cara menjalankan: ekstrak ZIP, buka folder di VS Code, lalu jalankan index.html dengan Live Server.
Kamera/GPS/sensor biasanya memerlukan HTTPS atau localhost serta izin browser.
Google Maps memerlukan API key milik pengguna di config.js.
Kamera dan sensor ponsel bukan pengganti teodolit terkalibrasi.
Jangan melihat Matahari melalui teleskop tanpa filter Matahari yang sesuai.
